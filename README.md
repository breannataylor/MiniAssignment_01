# MiniAssignment_01
Web Development I Mini Assignment 01

## Instructions
- Start with the “cis-dept.html” in the “Ch 4 Part 2 Exercise Code.zip” file
- A blank CSS file in the css folder has been provided for you called “css-dept.css”
- For descendant p tags of the main element, set the font-weight to “bolder”
- For general sibling p tag of an ol element, set the color to “teal”
- For all child li tags of an ol tag, set the color to “coral”, font-weight to “bold”, and line-height to 1.4em
- For both the footer and the h1 elements, set the color to “darkslategrey”
- For all a tags with an href attribute, set the color to “seagreen” and font-weight to 900
- For all li tags with a class of programmer, set the color to “darkorchid” and font-variant to “small-caps”
- Practice using the developer tools to inspect your CSS!
